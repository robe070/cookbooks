LANSA Scalable License version 16.0

This virtual machine must be instantiated using the supplied Azure Resource Manager (ARM) template referred to below. You only need to RDP into the instance in order to troubleshoot issues when creating the LANSA stack using the ARM template.

Before you begin, you should ensure that you have the skills necessary to use LANSA effectively. If you need LANSA training, various lessions are available at learn.lansa.com

Do not use this Azure image until you have produced a LANSA application with the LANSA IDE.

Full instructions for using the template and creating your stack are provided here: Microsoft Azure Tutorial

A summary of the steps involved are:

  1. Subscribe to the LANSA Scalable License.
  2. Upload your LANSA Web Application MSI to Azure storage – and obtain the URL of the MSI.
  3. Use the Azure Portal to create a scalable LANSA stack using the template URL provided above.
  4. You will be prompted to enter various parameters. The parameters listed in the Basic blade are all you need to consider to instantiate a stack that will work. The rest are tuning or maintenance parameters which you only need to consider when creating a production stack. In particular you need to put the URL of the MSI in parameter Lansa MSI URL and provide answers for the other mandatory parameters – passwords and SSL certificate.
